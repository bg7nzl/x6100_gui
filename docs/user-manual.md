# X6100 使用说明（BG7NZL 定制固件）

> 本文只讲日常操作，不讲技术原理，照步骤做即可。
> 适用于在 gdyuldin upstream 基础上集成的 BG7NZL 侧载固件（含重写后的 FT8，以及浏览器 Remote / Logbook / OTA 等）。如果你还在用原厂系统、或没从本 TF/SD 卡启动，下面大部分功能都不存在。
> 使用前请先读 [免责声明](DISCLAIMER.md)。

开发说明在同目录的其它文档里，普通使用不用打开。

---

## 如何刷入本固件（侧载）

本固件通过 TF/SD 卡侧载运行：原厂系统还在机内 eMMC，本系统在外接卡上。取下卡正常开机，一般就回到原厂系统，不会覆盖机内的原厂镜像。

### 准备

1. 先确认基带（BASE）版本是 1.1.9（System Info → BASE）。低于 1.1.9 请先升级基带，再写 SD 卡镜像。
2. 准备一张 SD 卡（容量以维护者给的 `sdcard.img` 为准，建议 Class 10 或以上）。
3. 从维护者处拿到 `sdcard.img`。

### 把镜像写入 SD 卡

Windows：

- 用 [Rufus](https://rufus.ie/) 或类似工具。
- 选 SD 卡和 `sdcard.img`，以 DD 镜像方式写入，不要只把单个文件拷到卡上。

Linux / macOS：

- 先确认设备名（如 `/dev/sdb`、`/dev/disk4`），写错盘会清空整块硬盘。
- 示例：

```bash
sudo dd if=sdcard.img of=/dev/disk4 bs=1m conv=sync
```

写完安全弹出。

### 开机使用

1. 电台完全关机。
2. 插入写好的 SD 卡。
3. 开机，从 SD 卡启动本固件。

使用中别拔卡，热插拔可能死机或损坏文件系统。

### 恢复原厂系统

1. 正常关机。
2. 取下 SD 卡。
3. 再开机，一般就从机内 eMMC 启动原厂系统。

---

> 重要：基带（BASE）必须是 1.1.9。低于这个版本可能出现瀑布缩放错位、IF/FFT 异常、FT8 和 DSP 行为异常等。请先升级基带再用本镜像。

### 关于 FT8（请先读）

本固件里的 FT8 通联和自动逻辑相对上游做了整体重写（无状态 QSO 引擎），不只是“多几个按钮”。目标是在忙频、多人呼叫、自动 / 手动切换时更跟手，但仍可能和上游行为不一致，请当成测试向的增强版来用，遇到异常反馈维护者（说清 Auto / TX CQ 状态、屏幕提示、大致频率就行）。

| 类别 | 能力 | 你在哪用到 |
|------|------|------------|

## 一、用之前先确认

1. 呼号和网格设好了。
2. 天线接好，驻波正常。
3. 遵守法规；FT8 禁止无人值守自动发射。
4. FT8 功率与散热（必读）：进 FT8 后放开到 10 W（上游原本限 5 W；设得更高会钳到 10 W 并提示）。10 W 一定要配合外部主动散热（比如对着机身 / PA 吹风扇）。FT8 占空比高，风冷不够 PA 可能很快就坏。没法保证散热就用 5 W 或更低，并缩短连续发射时间。
5. BASE = 1.1.9。
6. FT8 属于增强 / 测试向，遇到问题反馈维护者。

---

## 二、怎么进 FT8

1. 主界面 APP → FT8。
2. 中间是解码列表，右侧是功能按钮（分 4 页）。

退出：按返回键离开。没完成的通联退出时可能按规则刷进日志（见「日志与记录」）。

---

## 三、FT8 按钮怎么翻页

按 「Page: n:4」 循环翻页。

| 页 | 按钮 |
|----|------|
| 1 | Free MSG · TX CQ · Auto · Auto Mode |
| 2 | Show（CQ/All）· Mode（FT8/FT4）· Hold Freq · TX Call |
| 3 | Force QSO save · CQ Modifier · Time Sync · Auto DNF |
| 4 | Processor（日常 / NA VHF 等） |

---

## 四、手动通联（自己点列表）

最稳的方式。

1. Auto 设成 Off（第 1 页）。
2. TX Call 设成 Enabled（第 2 页）。
3. 在解码列表里选中一行并确认（点这条消息）。
4. 电台生成下一句，在合适时隙发出去。
5. 对方再回后继续跟，直到 73 收场。
6. 完成时通常会提示「Saved QSO de …」。

小提示：

- 可点的不只是 CQ：别人通联中途的行、别人的 RR73/73，也会按「叫对方」开叫（类似 WSJT-X 双击）；叫你的消息则按阶梯回下一步。
- 点了列表会关 CQ、Auto 回 Off，跟这一台。
- 对方连着几轮不出声，最多再试约 5 轮就自动停，免得空发。
- 正在发射时再操作，可能会停发（TX Call 关掉），以机内为准。
- 某条应答如果赶不上时隙开头，本隙可能不发、下一隙重新算，这是正常的。

## 五、自动选台（Auto 与 Auto Mode）

### 5.1 Auto

| 显示 | 含义 | 适用 |
|------|------|------|
| Off | 不自动 | 纯手动 |
| Res | 只回答呼叫你的人，不主动叫别人的 CQ | 开着 TX CQ 等别人来叫 |
| Full | 还会主动叫列表里别人的 CQ | 省力，且有人看守 |
| Pre | 还能在别人快结束时插叫（tail-end） | 老手、频点挤时 |

### 5.1.1 主动叫台要你点头（Full / Pre）

Full / Pre 要主动叫一个**这次进 FT8 后还没叫过**的台时，不会直接发射，屏幕会提示：

```text
TX2 BH4XXX? PTT/VFO=OK
```

- **同意**：按一下 PTT（长按短按都行），或转一下大旋钮（VFO）。按得及时（FT8 约 5 秒、FT4 约 1.5 秒内），这一轮就把台叫出去。
- **不理它**：超时自动作罢，一瓦不发。同一个台下次再出现还会再问，直到你点头为止。
- 点过头的台这次会话内不再问；你手动点过的台也算点过头。退出 FT8、切 FT4/FT8、换波段后名单清零，重新来。

几个细节：

- 确认时转 VFO **不会**动频率，确认完立刻恢复正常调谐。
- 进了 FT8 界面，PTT 就不再控制发射（FT8 里它本来没用），专职当确认键。
- 对方主动叫你的应答（回报告、RR73、73）不需要确认，照常自动走完。
- 提示只显示在机身屏幕上，**没有提示音，也不会推送到网页 Remote**。所以 Full / Pre 叫新台必须有人守在机器旁看着屏幕——这是有意的：FT8 本来就禁止无人值守自动发射。

### 5.2 Auto Mode（多人时选谁）

| 显示 | 优先 |
|------|------|
| SNR | 信号最好 |
| Dist | 距离最远（要网格完整） |
| Rnd | 随机 |
| Grid | 还没通联过的新网格 |

Auto Mode 的选择会记住；Auto 每次进 FT8 默认都是 Off，要手动打开。

自动模式大致还会：

- 别人呼叫你时优先应答；
- 已经通联过的台一般不再主动叫（对方再叫你还是会应）；
- 同一个 CQ 连续失败会短暂跳过，不死磕；
- 主动叫新台前先弹提示等你按 PTT/VFO 点头（见 5.1.1）；
- Pre 可以在 RR73/73 收尾后插叫，拥挤时慎用。

### 5.3 解码列表颜色（看 CQ 时）

| 外观 | 含义 |
|------|------|
| 亮绿 CQ | 本频段模式还没通联过 |
| 深绿 CQ | 通联过，但不是当前频段 + 模式 |
| 删除线 CQ | 当前频段 + 模式已通联过（自动一般不去叫） |
| 红色 | 呼叫你（to me） |

### 5.4 手动和自动别混用（经验）

- 点了列表某一行，倾向关 CQ、Auto 回 Off，跟这一台。
- 改 Auto / Auto Mode，通常会关 CQ、重开自动逻辑。
- 打开 TX CQ，Auto 常会自动变成 Res。

以机内实际提示为准。

## 六、自己发 CQ（TX CQ）

| 显示 | 含义 |
|------|------|
| Off | 不叫 |
| Even | 整点、30 秒等时段发 CQ |
| Odd | 15 秒、45 秒等时段发 CQ |

相对上游只有“开 / 关”，本固件用 Even/Odd 指定奇偶时隙。

1. 设好呼号、网格。
2. TX CQ 选 Even 或 Odd。
3. 看到「Next TX: CQ …」后按设定重复。
4. 有人叫你时优先应答，CQ 让位；这段结束后可以再叫。
5. 叫满次数没人应，TX CQ 可能自动回 Off。
6. 停叫：切回 Off。

CQ Modifier（第 3 页）给 CQ 加后缀（如 `POTA`、竞赛相关）。NA VHF 下 Processor 也可能影响修饰，见第十一节。

---

## 七、Free MSG（自定义短句）

第 1 页 Free MSG：最多 13 字符，预约发射。

允许字符：空格、数字、A–Z，以及 `+ - . / ?`（小写会转成大写）。

常见的：`TU 73`、`PSE QSY`、`QSO B4` 等。

1. 按 Free MSG，输入，确认。
2. 会关掉 TX CQ，并预约下一个可发时隙（赶不上本隙就下一个同奇偶隙）。
3. 提示「Next TX: …」。
4. 发出去之前，自动通联 / CQ 不会覆盖这条短句。
5. 上次内容会记住。

字符不合法或过长会提示失败，不发射。

---

## 八、第 2 页其它按钮

| 按钮 | 作用 |
|------|------|
| Show: CQ / All | 只显示 CQ，或显示全部解码 |
| Mode: FT8 / FT4 | 切换协议（会清掉当前 FT8 会话） |
| Hold Freq: Disabled | 跟随时跳到对方频率 |
| Hold Freq: Enabled | 守本频，只标记对方位置 |
| TX Call: Enabled / Disabled | 总开关；关了就只收不发 |

---

## 九、第 3 页其它按钮

| 按钮 | 作用 |
|------|------|
| Force QSO save | 把“报告已齐、还没正式 73”这类记录批量写进日志 |
| CQ Modifier | CQ 后缀 |
| Time Sync | 校到 FT8 节拍（解码不正常时试试） |
| Auto DNF | 自动抑制本地强尖峰（下一节），常见默认 On |

TX 尾对齐没有按钮：起步稍晚时可能裁掉波形前段来对齐结尾，而不是整段乱发。

## 十、Auto DNF（抑制本地强台）

### 解决什么问题

旁边的大功率 SSB、强载波、窄尖峰会顶住前端，弱 FT8 就解不出几个。Auto DNF 在每个时隙自动找一个明显高出底噪的窄峰，临时加一个约 70 Hz 宽的陷波，等退出时隙或你要发射前再撤掉。

### 你需要知道的

1. 大约在时隙开始后 0.25～0.75 s 扫描（FT8 一隙约 15 s）。
2. 默认要高出底噪约 40 dB 才陷波（可以用 `/mnt/` 下的参数文件微调，见下）。
3. 你即将发射时会先撤陷波；退出 FT8 会恢复进入前的 DNF。
4. 如果主界面已经开了 DNF Auto，FT8 的 Auto DNF 可能让位，避免两套打架。

### 瀑布提示

| 显示 | 含义 |
|------|------|
| 蓝竖线 + dB | 检测到强峰，还没陷波（没到阈值或 Off） |
| 红竖线 + dB | 已经临时加了陷波 |

### 怎么用

| 情况 | 建议 |
|------|------|
| 一般操作 | 保持 On |
| 解码突然变少、有强尖峰 | 确认 On，看竖线和 dB |
| 不想动 DNF | Off |
| 主界面长期开 DNF Auto | 只留一种就行 |

### 高级调参（可跳过）

`/mnt/` 下的单行数字文件（没有会建默认值）：

| 文件 | 默认 | 作用 |
|------|------|------|
| `auto_notch_threshold_db.txt` | 40.0 | 相对底噪的阈值 (dB) |
| `auto_dnf_scan_start_sec.txt` | 0.25 | 开始扫描 (s) |
| `auto_dnf_scan_end_sec.txt` | 0.75 | 结束扫描 (s) |
| `auto_dnf_clear_time_sec.txt` | 0.25 | 时隙末提前撤陷波 (s) |

## 十一、Processor / NA VHF（第 4 页）

1. Processor 切到 NA VHF（或机内显示的竞赛档）。
2. 交换以呼号加网格（含 `R 网格`）为主，不是日常那种多步信号报告。
3. CQ 可能带竞赛相关的修饰。
4. 赛后切回日常档，免得格式发错。

赛规以主办方为准。

## 十二、日志与记录在哪里

### 通联 ADIF

- 完成通联，提示 Saved 就写入了。
- 文件：`/mnt/ft_log.adi`。
- Force QSO save 也写同一个文件。

### FT8 详细收发日志

- `/mnt/ft8_logs/x6100_log_<时间>.txt`。
- 大致是 `RX,…` / `TX,…` 每行的解码和发射，方便复盘，不是 QSO 汇总。

### 系统发射诊断日志

- `/mnt/tx_logs/tx_log_<时间>.txt`。
- 各模式的 TX 事件，维护者排障用，普通通联不用打开。

### 其它

- Free MSG 记忆：`/mnt/ft8_freetext.txt`。
- Worked 库：`/mnt/qso_log.db`（可以用网页 Logbook 清空）。
- 导入用：`/mnt/incoming_log.adi`（Logbook 上传后由电台导入）。

不清楚路径就用网页的 File browser / Logbook。

## 十三、手机或电脑：网页功能

让电台连上 Wi-Fi，浏览器打开 `http://电台IP/`（例：`http://192.168.1.50/`）。

### 13.1 Remote（遥控）

1. 顶部点 Remote。
2. 按键（POWER、PTT、BAND、MODE、F1–F5 等）、旋钮（VOL / MFK / VFO）、刷新屏幕截图。
3. 遥控整机，不只是 FT8；进 FT8 还是要在界面里操作 APP → FT8。
4. 建议只在自家局域网用；远程 PTT 和在机身上按一样，必须有人看守。截屏没就绪时稍后再刷新。

### 13.2 Logbook（通联库）

| 操作 | 说明 |
|------|------|
| 表格 | 浏览 `/mnt/ft_log.adi` |
| Download | 下载本地 ADI |
| Delete | 删除本地 ADI（会短暂重启界面） |
| Upload | 上传 WSJT-X / LoTW 等 `.adi`，导入 worked |
| Reset qsolog | 清空 worked 数据库 |

上传 / 删除 / 清空时屏幕可能黑一下，正常。

### 13.3 OTA（只更新界面程序）

OTA 可以替换机内的 GUI 程序，不用重写整张 SD。

包的要求：zip 里只有一个文件，文件名等于该文件内容的 sha256（64 位小写十六进制）。成功后界面会重启。

```bash
sha=$(sha256sum x6100_gui | awk '{print $1}')
cp x6100_gui "$sha"
zip -j gui-ota.zip "$sha"
```

OTA 不更新网页服务本身；Web 有大改时还是得按维护者说明更新镜像或 Web 组件。

### 13.4 其它菜单

| 菜单 | 用途 |
|------|------|
| File browser | 下载 ADIF、ft8_logs、tx_logs、截图、录音等 |
| Time Editor | NTP / 手动校时 / 时区（FT8 强烈建议先对时） |
| dmesg | 内核日志尾部，故障时截图给维护者 |
| Bands / Digital modes / General | 改波段和数字频率等（有把握再动） |

File browser：大文本可能只显示一截，完整内容请下载。下载 `params.db` 时如果电台正在写库，偶尔会拿到不完整的副本，以机内文件为准。

## 十四、几种推荐用法

安静手动：

- Auto: Off · TX Call: Enabled · 点列表

自己叫 CQ 等人来：

- TX CQ: Even 或 Odd（Auto 常为 Res）· TX Call: Enabled

少动手、自动找 CQ（必须有人看着）：

- TX CQ: Off · Auto: Full 或 Pre · Auto Mode: SNR 或 Grid · TX Call: Enabled

只听不发：

- TX Call: Disabled

发一句短话：

- Free MSG

北美 VHF 数字赛等：

- Processor → NA VHF，赛后改回

## 十五、安全与礼貌

1. 这不是无人值守工具，随时能关 TX Call 或退出 FT8。
2. 别长时间无意义占频，结束及时 73。
3. 10 W 加高占空比就必须外部主动散热；没法风冷别用满 10 W。
4. 遥控只在自家 Wi-Fi，别把管理页暴露到公网。
5. 详见 [免责声明](DISCLAIMER.md)。

## 十六、常见问题

问：列表一直没有解码？
答：看频率是不是在 FT8 段、Mode 对不对，试试 Time Sync，检查天线和驻波。

问：点了消息提示 Invalid message？
答：常见是叫你的 73（无话可回）、残缺解码，或根本解析不出对方呼号。别人中途的 GRID/报告一般可以点，会开叫对方。

问：自动不去叫某台 CQ？
答：看是不是删除线 / 已通联、刚失败被跳过，或者改 Auto Mode / 改手动。

问：ft8_logs 和 tx_logs 有什么区别？
答：前者只记 FT8 的解码和发射；后者记各模式的发射事件，给维护者看。

问：通联中途想停发射？
答：TX Call 设 Disabled；要恢复再设回 Enabled。

问：手机打不开网页？
答：确认在同一 Wi-Fi、IP 正确、地址带 `http://`。

问：Free MSG 会不会和 CQ 打架？
答：确认后会关 TX CQ，并让位到发出为止，不用再等“TX busy”。

问：解码变少，像是本地强台？
答：看瀑布上的强尖峰，保持 Auto DNF On；还差就换频，或请维护者调阈值文件。

问：能用满 10 W 吗？
答：可以，但必须外部主动散热；否则用 5 W 或更低。

问：竞赛时还在发报告、不是网格？
答：检查第 4 页 Processor 是不是在 NA VHF。

问：OTA 之后网页菜单还是旧的？
答：正常，OTA 只换 GUI 程序。

问：Logbook 上传后 worked 没变？
